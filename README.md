## 这套教程适合谁

- 已经上手写过 skill，但被「**静默失败**」折磨的人——装了不触发、触发了不照做、照做了跑不动
- 想搞懂 skill 到底**怎么被模型「看见」**的人
- 不想看「skill 是什么」、只想知道「**出问题怎么查、怎么定位到哪一层**」的人

---

## 核心理念

skill 一辈子只和模型见三次面：**装好那刻、触发那刻、用到某个文件那刻**。三套见面规矩各不相同。

把它们摸清，「怎么写 skill」才从手感变成工程。

这套教程不按「教程腔」排，而按实际踩坑、搞懂的顺序——**每课都是一个真实的坑 + 一套可复用的诊断方法**。

## 课程目录

### 🔧 机制地基（1-5 课）

| 课 | 标题 | 一句话核心 |
|---|---|---|
| 01 | **上下文经济学** | 上下文按 token 计费、每轮都付。skill 全部设计逻辑从「见面要花钱」推出 |
| 02 | **description 是路由表不是简介** | 模型凭一行字决定用不用你；负边界必须写进 description 自己 |
| 03 | **正文不是文档，是快照** | 正文一次性注射、跨轮留存、逐行计费——按「没人会核对第二遍」来写 |
| 04 | **脚本不进门** | 脚本被执行、不装载。想归正文，查归 L3，做归脚本，借归现成工具 |
| 05 | **输入输出接口** | `$ARGUMENTS` / 预载 / fork 三张口。正文写兜底句，别赌机制 |

| 课 | 标题 | 一句话核心 |

| 07 | **子 agent 派工** | 派工不是雇人手，是**买干净**——付 token，买隔离 |

## 这套教程的三个坚持

**第一，全是真机实测，不抄文档。** 文里每个机制、每个数字、每个翻车现场，都是在本机跑出来的。哪句是验证过的、哪句是推测，文里会标清楚。

**第二，不写「是什么」，写「怎么诊断」。** 网上教程爱教「skill 有哪些字段」。这套不写这个——写的是「出问题你怎么知道、怎么查、怎么定位到哪一层」。因为 skill 的失败是**静默的**，会查比会写重要。

**第三，所有可对号入座的身份全部脱敏。** 公司、客户、内部路径、真人代号一概不出现；公开范例实名保留、可复现。
